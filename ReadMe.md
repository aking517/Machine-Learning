This is going to be a quickstart guide for HW1 of CSCI
4120 Machine Learning

The first step is installing a python IDE: I recommend Pycharm community. It 
is free, and it is what was used for this assignment. PyCharm community
is available to download for a Windows machine at the following url:
https://www.jetbrains.com/pycharm/download/?section=windows

Once pycharm community is set up, the .py file submitted to Canvas will be able to be opened.

In order to run the file correctly there are going to be certain libraries that must 
be installed for the code to run correctly, this can be done by clicking on
the 'Python Packages' icon to the left of the terminal within PyCharm.
The following packages will be installed:

-numpy

-pandas

-matplotlib

-scikit-learn

Once the correct python packages are installed, you just need to run the code using the run code button towards the top right. Once the code is run the results will be returned within a few seconds.

When looking at possible k-values, there were a couple of options that are in the 90% range. From the results and the line chart, it can be concluded that a k value of 1 to 6 is the most accurate.
Once our K-value gets passed 11 the accuracy gets much worse, this is due to the cruse of dimensionality.

The first line chart is an outlier in terms of the low accuracies, but it is seen that even with multiple runs once our k value 
eclipses 11 the accuracy dramatically falls.
